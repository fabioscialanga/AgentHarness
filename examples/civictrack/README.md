# oss-agent-bootstrap-example

Esempio generico di progetto pensato per essere open source e usato come input per un framework di bootstrap agentico.

Questo repository non rappresenta uno dei tuoi progetti reali. È un caso fittizio ma credibile, costruito per mostrare:
- come scrivere un `PROJECT.md`
- come strutturare un `project.yaml`
- quali artefatti generare per lavorare bene con agenti AI
- come includere test, sicurezza e governance minima fin dalla V1

## Progetto di esempio

Il progetto fittizio si chiama `CivicTrack`.

`CivicTrack` è una piattaforma open source per raccogliere segnalazioni civiche da cittadini e team comunali:
- buche
- illuminazione guasta
- rifiuti abbandonati
- manutenzioni di quartiere

L'obiettivo del progetto non è fare tutto, ma offrire una base solida e semplice per:
- ricevere segnalazioni
- validarle
- assegnarle
- tracciare lo stato
- notificare aggiornamenti

## File chiave

- `PROJECT.md` → descrizione umana del progetto
- `project.yaml` → configurazione strutturata per il framework
- `AGENTS.md` → regole operative per agenti AI
- `docs/ARCHITECTURE_SUMMARY.md` → sintesi architetturale
- `docs/DELIVERY_MODEL.md` → livelli di autonomia e review
- `workflows/` → template di task
- `checklists/` → definition of done, review, sicurezza, test
- `policies/` → policy macchina per test, sicurezza e autonomia

## Scopo dell'esempio

Questo esempio serve per open source:
- del modello di input
- delle policy minime
- dei workflow agentici
- della struttura iniziale di progetto

Non è un prodotto completo: è una base dimostrativa ma concreta.
